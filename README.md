# 2mriky Cut Bulk

أداة شخصية لإزالة خلفية الصور **بالجملة**، شغّالة 100% جوّه المتصفح.
مفيش سيرفر، مفيش رفع، مفيش اشتراك، مفيش حد أقصى لعدد الصور.

---

## ليه الجودة مش بتقل

ده الجزء المهم. البايبلاين مصمّم بحيث الصورة الأصلية **متتلمسش**:

| المرحلة | اللي بيحصل | تأثيره على الجودة |
|---|---|---|
| 1. فك الترميز | `createImageBitmap(file)` — بالأبعاد الأصلية الكاملة | صفر |
| 2. مدخل الموديل | نسخة **مصغّرة منفصلة** (1024px) بتتبعت للموديل | صفر — دي نسخة، مش الأصل |
| 3. الاستنتاج | الموديل بيرجّع **ماسك (alpha)** بس، مش صورة | صفر |
| 4. تكبير الماسك | الماسك بيتكبّر لـ W×H الأصلية بـ bilinear ناعم | يأثر على **دقة الحافة** بس، مش على الريزوليوشن |
| 5. التركيب | الماسك بيتكتب في قناة الألفا فوق البكسلات الأصلية | صفر — قنوات RGB زي ما هي |
| 6. الحفظ | PNG أو WebP Lossless | صفر |

**النتيجة:** أبعاد الخرج = أبعاد الدخل بالظبط. صورة 4032×3024 بتطلع 4032×3024.

> للمقارنة: remove.bg المجاني بيرجّعلك **625×400** مهما كانت صورتك كبيرة — ده الحيلة اللي بتخليك تدفع.

**الحد الوحيد الحقيقي:** الماسك بيتحسب على 1024px، فدقة الحافة على الشعر الرفيع محدودة بده (نفس حدود أي موديل تاني). سلايدر «حدّة الحواف» بيظبطها.

## الرفع على GitHub Pages

```bash
# 1. اعمل repo جديد على github.com (خليه public عشان Pages يشتغل مجانًا)
git init
git add .
git commit -m "2mriky Cut Bulk"
git branch -M main
git remote add origin https://github.com/USERNAME/bg-remover.git
git push -u origin main
```

بعدها: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**

اللينك هيبقى: `https://USERNAME.github.io/bg-remover/`

> لازم HTTPS (وGitHub Pages بيديه تلقائي) عشان WebGPU يشتغل.

### بدائل أسرع
- **Netlify Drop** (`app.netlify.com/drop`) — اسحب الفولدر، لينك live في ثانية، من غير terminal.
- **Vercel** — `vercel deploy` من الفولدر.
- **محليًا:** `python3 -m http.server 8000` وافتح `localhost:8000`. مش هيشتغل بـ `file://` لأن الـ ES modules محتاجة origin.

## المحرك

- **transformers.js v3** (Hugging Face) على ONNX Runtime Web
- **RMBG-1.4** من BriaAI — ≈44MB، متوازن
- **MODNet** — بديل أحسن للبورتريه والشعر
- **WebGPU** لو متاح، وإلا **WASM** تلقائي

الموديل بينزّل **مرة واحدة** أول تشغيل وبعدين بيتكاش في المتصفح (Cache API) — بعد كده شغّال أوفلاين.

### تغيير الموديل
في `index.html` جوه `<select id="model">` ضيف أي موديل ONNX متوافق مع transformers.js من Hugging Face.

### تثبيت نسخة المكتبة
في أول `app.js`:
```js
const TRANSFORMERS_CDN = 'https://cdn.jsdelivr.net/npm/@huggingface/transformers@3';
```
غيّرها لنسخة محددة (مثلاً `@3.7.5`) لو عايز تثبّت.

## ملاحظات

- **WASM بطيء نسبيًا على GitHub Pages** لأن Pages مش بيبعت هيدرز `COOP/COEP`، فالـ multithreading مقفول. لو جهازك فيه WebGPU (Chrome/Edge حديث) مش هتحس بفرق.
- **iOS Safari** عنده سقف مساحة كانفاس ~16.7 ميجابكسل. الصور الأكبر من كده بتتعلّم بعلامة ⚠ وممكن تفشل على الآيفون. على الديسكتوب عادي.
- **HEIC** مش مدعوم — المتصفح مش بيفك ترميزه. حوّله لـ JPEG الأول.
- **الألوان:** الكانفاس بيحوّل لـ sRGB. لو صورك Display-P3 أو Adobe RGB هتترجع sRGB. لشغل الطباعة الدقيق خد بالك من دي.
- **ZIP** بيتعمل بـ `STORE` (من غير ضغط) لأن PNG/WebP مضغوطين أصلاً — أسرع بكتير ونفس الحجم.
